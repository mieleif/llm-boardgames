# Reference assets (local only)

Put your own photos/scans of the physical **Toy Battle** game here (rulebook
pages, the player-aid card, the board) while working on the engine. They are a
handy reference for encoding board graphs and effects.

These files are **git-ignored on purpose**: the game's artwork, rulebook text,
and box images are © Repos Production and are licensed for strictly personal,
private use. We do not commit them to the repository. Only our own
programmatically generated renders (in `renders/`) and reimplemented game
mechanics live in version control.

If you add a new board, read the relevant photo here, encode the graph in
`toy_battle/boards/<name>.json`, and leave the photo in this folder.
